## Phase 1 自動作成ロジックの移植（1日）

LINE より先に、一番大事な中身を固める。**2段階に分けること**（`04`「単位のルール」を先に読む）。

### 1a デモと完全一致させる

- デモから `scheduler.js`（generate / checks / 補助関数）を純粋関数として切り出す。**時間単位のまま**（`minLen=3`, `maxLen=8`）
- `test/scheduler.test.mjs` を `04` の「テストで確認すること」で作り、`node --test` で通す
- **完了の確認**：デモと同じ入力で同じシフトが出る。ここを固定点にする

### 1b スロット単位へ変える

- 内部表現を「スロット番号」に統一し、分⇔スロットの変換を入口と出口だけに閉じ込める
- `lh` に `need > 0` 条件を足す、「不足」の表示を `スロット数 × grid/60` に直す、係数を `WEIGHTS` に外出しする
- **完了の確認**：1a のテストが通り続ける

一気にやると、スコア式の単位を取り違えて**全候補がマイナス点になり誰も配置されない**（エラーも出ない）。`04` の「単位のルール」参照。

## Phase 2 GAS の API（1〜2日）

- `Sheets.js`：列名で読み書きするヘルパ（`readTable(name)` → オブジェクト配列、`writeTable` など）。**1シート＝1回の `getValues()`** を契約にする
- `Api.js`：`doPost` で action を振り分け、エラーは `{ok:false,...}` で返す。書き込み系は `LockService.getScriptLock()` で囲む
- `Auth.js`：まずは **開発用モード**（スクリプトプロパティ `DEV_USER_ID` があればトークン検証をとばす）で作り、Phase 3 で本番の検証に切り替える
- スタッフ用 action（me / link / submit）を実装。`submit` は**行を削除せず `rev` を増やして追記**する
- **完了の確認**：GAS エディタのテスト関数から submit を呼ぶと Requests / Submissions に行が入る。同じ人が2回出すと rev が増え、読み出しは最新だけを返す

### ここで判断が要る（Webhook が動かない場合）

GAS は POST に対して別ドメインへリダイレクトを返す。LINE の Webhook がこれを追従するかは公式に記述がない。Phase 3 で次の3つを確認する：

1. LINE Developers コンソールの「検証」ボタンの結果
2. 実際にリッチメニューから提出して返信が届くか
3. LINE Developers の「統計情報」での Webhook エラー率

1が失敗しても2が成功するなら「動くが統計が汚れる」として受け入れる。**2も失敗するなら受付メッセージは諦める**（画面の完了表示だけで MVP は成立する）。署名検証を外部に出す案は、保守の複雑さに見合わないので今はとらない。

## Phase 5 確定とシフト表出力（1〜2日）

- **「_シフト表テンプレート」 を先に用意する。** 店からもらった元の Excel の名前バーと備考を消して枠だけ残し、スプレッドシートに取り込む。印刷設定（A4縦・余白・幅に合わせる）は手で1回設定する。Sheets API には印刷設定を触る手段がないので、コードから A4縦を指定することはできない
- `ShiftSheet.js`：テンプレートを `copyTo()` で複製し、Shifts から中身だけ書き込む（日ごとのブロック、勤務範囲のセルを結合して名前・色、行を詰める、備考、注意書き）
- 時刻の見出し行は**日ブロックごとに繰り返す**。軸は 7:00〜翌3:00。1日あたりの行数は `Settings.sheet_lanes`（既定12）。超えた日は店長画面に警告を出す
- `mgr.publish` と確定前の確認画面
- **完了の確認**：確定ボタンで「シフト表_2026-11-02」ができ、印刷プレビューが紙のシフト表に近い。**店長に見せて「いつもの表と同じ」と言ってもらう**

### この Phase を前倒しできるなら、した方がよい

`01` の成功の目安は「店長が“いつもの表と同じだ”と感じる出力」で、オーナーの一番の関心もここにある。元の Excel が手に入った時点で、**データを手入力した出力だけを先に作って見せる**と、一番不確実な「見た目の合意」を最初に取れる。合わないと分かるのが Phase 5 だと手戻りが大きい。
