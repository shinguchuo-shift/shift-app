→ 本番に進むうえで**まだ決まっていない**のは：**#20〜22**（お金・保守）、**#6**（8〜24時の時間帯ごとの必要人数）、**#19**（名前・LINE ID をスプレッドシートに置いてよいか）、**#15**（今の作成時間＝効果測定の基準値）、**#5**（5つのルールの「絶対」「できれば」）。

**グループLINEで使う件（2026-11-08 確認）**：LIFF は個人を識別するので**紐付けはそのまま動く**。
ただし ①受付メッセージがグループに流れるので出さない ②リッチメニューは入口にならないのでリンクを貼る
③**両チャネルを同じプロバイダーに作る**（別だと userId が食い違って紐付けが壊れる）。詳細は `03`。
#23 は「普通のグループ」と確認済み。さらに調べた結果、**LINE公式アカウントは作らなくてよい**ことが分かった（2026-11-08）。
LIFF は **LINEログインチャネル**に追加するもので、公式アカウント（Messaging API チャネル）には追加できない。
LINEログインは無料で、公式アカウントは前提ではない。通知は店長がグループに投稿する運用なので、無くても回る。
→ 初期設定が半分になり、月200通の縛り・Webhook の署名検証の問題も消えた。詳細は `07`。
あとから公式アカウントを足すときは、**同じプロバイダー**に作れば紐付けはそのまま使える。

**ピーク帯のルールの読み替え（要確認）**：レベル0〜3を廃止したため、「ピーク帯はレベル3を1人以上」を
**「ピーク帯は各側に研修中でない人を1人以上」** に読み替えて実装した。これで意図に合うか確認する。
